# TMP Camera Surveillance Next 2.20.35

Adds a downloadable Linux x86_64 desktop client to the authenticated interface. Install the client on a Linux workstation with `sh ./install-linux.sh` after extracting the ZIP; Node.js 20+ and npm are required, and the first installation downloads the Electron runtime. The client opens the existing server without requiring a browser window or second surveillance server.

Existing ZIP / GitHub updates, camera settings, recordings, server credentials and data mounts are preserved.
